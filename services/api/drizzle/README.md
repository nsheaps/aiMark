# Migrations

SQL migrations generated by drizzle-kit from `src/db/schema.ts`:

```sh
bunx drizzle-kit generate --name <change>
```

Generated files are committed.

## How they are applied

- **Local dev + tests (bun:sqlite)**: `src/db/migrate.ts` applies these files
  at startup (entrypoints/bun.ts) and in test setup, tracking applied files in
  a `__aimark_migrations` table.
- **Production (Cloudflare D1)**: the deploy workflow applies the same files
  before deploying the Worker:

  ```sh
  wrangler d1 migrations apply aimark --remote
  ```

  (`migrations_dir = "drizzle"` is set on the D1 binding in `wrangler.toml`;
  wrangler ignores the `meta/` bookkeeping directory.)
